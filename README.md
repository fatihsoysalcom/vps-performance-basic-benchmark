# VPS Performance Basic Benchmark

This example provides a basic, self-contained benchmark suite to measure CPU, memory, and disk I/O performance. It simulates common server workloads to give a quick indication of a system's raw speed, similar to how a VPS's performance might be initially assessed. This helps in understanding fundamental resource capabilities.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
